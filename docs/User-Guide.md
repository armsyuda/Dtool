# DTool 0.1 사용 설명서

## 설치와 업데이트

1. [GitHub 릴리스](https://github.com/armsyuda/Dtool/releases/latest)에서 Windows x64 설치 파일을 내려받아 실행합니다.
2. 설치가 끝나면 시작 메뉴에서 **DTool**을 엽니다. 시작 메뉴의 **DTool** 폴더에는 사용 설명서와 MCP 연결 가이드도 있습니다.
3. DTool은 시작할 때 GitHub의 최신 공개 버전을 확인합니다. 새 버전이 있으면 상단 바의 다운로드 아이콘이 색상으로 바뀝니다. 아이콘에 마우스를 올리면 버전이 표시되고, 클릭하면 다운로드 페이지가 열립니다.

## 문서 만들기와 저장

- **파일 → 새로 만들기**에서 문서 프리셋을 고릅니다. 환경에 맞춰 크기, 단위, 해상도 또는 페이지 옵션을 정한 후 문서를 만듭니다. 기본 프리셋으로 바로 만들려면 프리셋을 더블클릭합니다.
- **파일 → 저장** 또는 **다른 이름으로 저장**으로 편집 가능한 원본을 보관합니다. 제출용 파일은 **파일 → 내보내기**에서 형식과 범위를 골라 별도로 만듭니다.
- 인쇄물 작업에서는 문서의 여백과 재단 여유를 확인하고 PDF에서 내보낼 범위를 선택합니다.
- U.S. Web Coated (SWOP) v2가 필요한 경우 Adobe에서 ICC 프로필을 받아 문서의 색상 프로필로 가져옵니다.

## 벡터와 레이아웃

- **벡터**에서 도형과 곡선을 그리고, 선택 도구로 위치와 크기를 조절합니다. 커브의 점과 핸들은 노드 도구로 편집합니다. 여러 작업 면은 아트보드 도구로 관리합니다.
- **레이아웃**에서는 페이지 패널에서 편집할 페이지를 선택합니다. 펼침과 표지 설정은 문서 설정에서 확인합니다. 반복되는 요소는 마스터 페이지를 만들어 적용할 수 있습니다.
- 캔버스 위 옵션 바는 현재 도구와 선택에 맞춰 바뀝니다. 레이어 패널에서 순서, 표시, 잠금을 관리하고, 색상·획·문자·문단 패널에서 세부 항목을 조정합니다.
- 상단 보기 전환으로 벡터 보기, 픽셀 보기 또는 외곽선 보기를 고를 수 있습니다. 보기 전환은 문서나 내보내기 형식을 바꾸지 않습니다.

## AI에서 문서 조작

같은 Windows PC에서 DTool을 실행하고 [MCP 연결 가이드](MCP-Guide.md)를 따라 AI 도구를 연결합니다.
